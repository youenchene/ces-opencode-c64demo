# References

## Hardware and 6502

- Codebase64 (the demo coder's wiki, with stable raster, FLD, sprite multiplexing, etc.): https://codebase64.org
- "The MOS 6567/6569 video controller (VIC-II) and its application in the Commodore 64", Christian Bauer
  (the VIC timing bible, covering badlines and borders): search "vic-ii.txt"
- 6502 instruction reference with cycle counts: https://www.masswerk.at/6502/6502_instruction_set.html
- C64 memory map ("Mapping the C64"): https://www.pagetable.com/c64ref/c64mem/
- C64 KERNAL/BASIC disassembly and ROM docs: https://www.pagetable.com/c64ref/
- C64 Wiki: https://www.c64-wiki.com

## Tools

- ACME manual (QuickRef.txt, AllPOs.txt, in the Homebrew share dir): `brew --prefix acme`, or
  https://sourceforge.net/projects/acme-crossass/
- VICE manual: https://vice-emu.sourceforge.io/vice_toc.html
- Exomizer: https://bitbucket.org/magli143/exomizer
- CharPad / SpritePad (Subchrist Software), GoatTracker 2, SID-Wizard
- HVSC: https://hvsc.c64.org

## Demoscene

- CSDb (the C64 scene database: demos, groups, tools, often with source code): https://csdb.dk
- Pouët: https://www.pouet.net
- "Bumbershoot Software" C64 articles, and Dustlayer tutorials (dustlayer.com), which are approachable
  intros to raster IRQs and scrollers.
